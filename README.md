# School Results Report

An analysis of exam results for 120 learners across Grades 4 to 6 and four subjects (Mathematics, English, Science, Kiswahili), built in R with tidyverse and R Markdown.

Live report: https://charisaladh.github.io/School-results-report/

## What it shows
- Class summary per grade
- Top 10 learners by total score
- Average score by subject
- Distribution of CBC performance levels (EE, ME, AE, BE)

## Tools
R, RStudio, tidyverse (dplyr, tidyr, ggplot2), R Markdown

## Note
All learner data is randomly generated practice data. No real learners are included.
